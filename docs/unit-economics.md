# Deal economics

```text
standalone annual cost = asset operating costs + shared NewCo platform costs
annual run-rate delta = parent-allocated run cost - standalone annual cost
one-time cost = program cost + disruption contingency + TSA forecast cost
three-year net value = 3 × annual run-rate delta - one-time cost
synergy realization = annual run-rate delta / purchase-case synergy
```

The model must include dual running, TSA charges, extension penalties, data migration, identity and network separation, licenses, integration, testing, contingency and post-close operations. It is not a valuation model and does not replace financial, tax or legal diligence.
